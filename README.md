# 智能体设计模式 · 33 讲中文有声精讲

把《Agentic Design Patterns》拆成 33 讲、每讲 3–5 分钟的中文有声精讲，并配一个可直接打开的网页播放器。通勤、散步时听完整本书的 21 个模式。

## 开始使用

用浏览器打开 `index.html` 即可收听；也可把本仓库部署到 GitHub Pages。

## 目录

| 路径 | 说明 |
| --- | --- |
| `index.html` | 网页播放器 |
| `data.js` / `lessons.json` | 33 讲的标题、分组与讲稿 |
| `audio/` | 33 个分讲 mp3 |
| `tools/tts_build.py` | 音频生成脚本 |
| `智能体设计模式_开源中文翻译版.pdf` | 原书中文版，供对照阅读 |
